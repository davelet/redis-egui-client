# Rudist

A modern Redis GUI client built with Rust + egui.

## Features

- Multi-tab connections
- String, List, Hash, Set, ZSet support
- JSON auto-format
- Keyboard shortcuts
- Async I/O, fast performance

## Supports

- macOS (Apple Silicon / Intel)
- Windows

## Quick Start

```bash
cargo run
```

See [Install](install.md) for details.
