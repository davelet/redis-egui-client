## ⌨️ Keyboard-First Design

Every action has a shortcut. Press `Cmd/Ctrl + E` to open the AI panel, `1-9` for quick connect, `Cmd/Ctrl + 1-9` for tab switching.

**Most used shortcuts:**

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl + E` | Toggle AI Panel |
| `Cmd/Ctrl + N` | New Connection |
| `Cmd/Ctrl + T` | New Tab |
| `Cmd/Ctrl + R` | Refresh Key |
| `Cmd/Ctrl + F` | Focus Filter |
| `1-9` | Quick Connect |

👉 See [Keyboard Shortcuts](shortcuts.md) for the complete list.

## Interface Overview

Rudist uses a multi-tab design with four main areas:

- **Top Panel**: Connection management, database selection, settings
- **Left Sidebar**: Key list, filter search
- **Central Panel**: Key value viewing and editing
- **Bottom Status Bar**: Connection status, key statistics

For detailed information, see [Interface](interface.md).
