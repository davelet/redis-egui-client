## 概述

Rudist 是一个基于 Rust + egui 构建的现代化 Redis GUI 客户端。

### 主要特性

- **多标签连接** - 同时管理多个 Redis 连接
- **完整数据类型支持** - String、List、Hash、Set、ZSet
- **JSON 自动格式化** - 智能解析和展示 JSON 数据
- **键盘快捷键** - 高效操作无需鼠标
- **异步 I/O** - 快速响应、高性能
- **AI 辅助** - 自然语言转 Redis 命令

### 系统支持

- macOS (Apple Silicon / Intel)
- Windows

## 连接操作

### 新建连接

点击顶部工具栏的「新建连接」按钮，或使用快捷键 `Cmd+N`。

### 连接参数

| 参数 | 说明 |
|------|------|
| 连接名称 | 标识连接，方便记忆 |
| 连接地址 | Redis 服务器地址（IP 或域名） |
| 端口 | 默认 6379 |
| 密码 | 如有需要填写 |
| 数据库 | 连接后选择的数据库索引（0-15） |

### 自动连接

应用启动时会提示恢复上次未关闭的连接，可在设置中启用或禁用此提示。

## 键操作

### 过滤键

在键列表上方的过滤框中输入关键词，按 `Enter` 键搜索。支持通配符 `*`。

### 刷新键列表

按 `Cmd+R` 重新加载当前数据库的所有键。

### 新建键

右键键列表空白区域，选择「新建键」。

### 删除键

选中键后按 `Delete` 键，或右键选择「删除」。

### 复制键名

选中键后点击复制按钮，或右键选择「复制键名」。

## 值查看器

### 支持的数据类型

| 类型 | 显示方式 | 操作 |
|------|----------|------|
| **String** | 纯文本 | 编辑、复制 |
| **List** | 索引列表 | 增删改元素 |
| **Hash** | 字段-值对表格 | 增删改字段 |
| **Set** | 成员列表 | 增删成员 |
| **ZSet** | 带分数的成员列表 | 增删改分数 |

### JSON 格式化

自动检测并格式化 JSON 数据，支持语法高亮和折叠。

### TTL 操作

- 查看剩余过期时间
- 修改 TTL 值
- 移除过期时间

## 命令行

### 打开命令行

按 `` ` ``（反引号）打开命令行面板。

### 功能模式

- **普通模式** - 直接输入 Redis 命令
- **AI 模式** - 用自然语言描述操作，AI 自动转换为 Redis 命令

### 使用示例

```
# 普通命令
GET mykey

# AI 模式
查看所有包含 "user" 的键
```

## 设置

### 主题设置

- **浅色模式** - 白色背景
- **深色模式** - 深色背景，适合夜间使用

### 语言设置

- English - 英文界面
- 中文 - 中文界面

### 快捷键自定义

所有可自定义的快捷键都可在设置中修改。点击快捷键设置中的输入框，然后按新的键组合即可。

### AI 配置

如需使用 AI 辅助功能，在设置中添加 API Key 和选择模型。
