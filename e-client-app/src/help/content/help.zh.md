## 概述

Rudist 是一个基于 Rust + egui 构建的现代化 Redis GUI 客户端。

### 主要特性

- **多标签连接** - 同时管理多个 Redis 连接
- **完整数据类型支持** - String、List、Hash、Set、ZSet
- **JSON 自动格式化** - 智能解析和展示 JSON 数据
- **键盘快捷键** - 高效操作无需鼠标
- **异步 I/O** - 快速响应、高性能
- **AI 辅助** - 自然语言转 Redis 命令（对话模式和代理模式）

### 系统支持

- macOS (Apple Silicon / Intel)
- Windows

## 连接操作

### 新建连接

点击顶部工具栏的「新建连接」按钮，或使用快捷键 `Cmd+N`。

### 连接参数

| 参数 | 说明 |
|------|------|
| 连接名称 | 标识连接，方便记忆 |
| 连接地址 | Redis 服务器地址（IP 或域名） |
| 端口 | 默认 6379 |
| 密码 | 如有需要填写 |
| 数据库 | 连接后选择的数据库索引（0-15） |

### 自动连接

应用启动时会提示恢复上次未关闭的连接，可在设置中启用或禁用此提示。

## 键操作

### 过滤键

在键列表上方的过滤框中输入关键词，按 `Enter` 键搜索。支持通配符 `*`。

### 刷新键列表

按 `Cmd+R` 重新加载当前数据库的所有键。

### 新建键

右键键列表空白区域，选择「新建键」。

### 删除键

选中键后按 `Delete` 键，或右键选择「删除」。

### 复制键名

选中键后点击复制按钮，或右键选择「复制键名」。

## 命令行

### 打开命令行

按 `Cmd+E`（macOS）或 `Ctrl+E`（Windows）打开命令行面板。

### 功能模式

- **普通模式** - 直接输入 Redis 命令
- **AI 对话模式** - 无状态：将自然语言翻译为一条 Redis 命令
- **AI 代理模式** - 有状态：使用工具与 Redis 交互（查看、编辑、删除键等）

### AI 对话模式

单条命令翻译。例如：
```
# 我有哪些键？
KEYS *
```

### AI 代理模式

多轮对话，可使用 Redis 工具：
- 查看/搜索键，查看键详情（类型、TTL、值）
- 编辑键值、设置过期时间、重命名键
- 删除键
- 执行任意 Redis 命令
- 切换数据库
- 管理 Hash、List、Set、ZSet 数据结构

例如：
```
# 查看所有 user 开头的键
→ filter_keys("user:*")

# session:123 里有什么？
→ get_key_info("session:123")

→ filter_keys("cache:*") → delete_keys([...])
```

### 中断 AI 请求

如果 AI 响应过慢，或代理模式（Agent）正在执行非预期的操作：
- 点击状态文字旁出现的红色方块按钮（**🟥**）。
- 即可立即中止远程请求并停止所有后台进程。
- **注意：** 为防止误触，该操作没有提供键盘快捷键。

## 设置

### 主题设置

提供 11 种内置主题：

| 主题 | 说明 |
|------|------|
| **System** | 跟随系统深色/浅色偏好 |
| **Light** | 浅色背景 |
| **Dark** | 深色背景 |
| **Dracula** | 紫色主题 |
| **Nord** | 北欧冷灰蓝 |
| **Gruvbox** | 复古暖色 |
| **Monokai** | 编程高亮风格 |
| **One Dark** | Atom 编辑器风格 |
| **Tokyo Night** | 东京夜景 |
| **Solarized Dark** | Solarized 深色 |
| **Solarized Light** | Solarized 浅色 |

切换主题即时生效。

### 全局字体

- **全局等宽** - 对所有文本应用等宽字体（否则只用于查看数据）

### 语言设置

- English - 英文界面
- 中文 - 中文界面

### 连接设置

- **在新标签页打开连接** - 启用后，新连接将在单独标签页中打开
- **自动连接** - 启动时自动连接上次使用的连接
- **显示未关闭的连接** - 提示恢复上次会话的连接
- **允许重复连接** - 允许多次连接到同一 Redis 服务器

### 显示设置

- **按冒号分组键** - 使用 `:` 作为分隔符分层组织键（如 `user:123:name`）
- **自动刷新 TTL** - 自动刷新键的过期时间显示
- **自动展开复合类型** - 当成员数量低于阈值时自动展开 Hash、List、Set、ZSet

### 更新设置

应用支持自动检查新版本，检查结果来自 GitHub Releases。

- **启动时检查更新** - 启用后，每次启动时自动检查是否有新版本
- **检查频率** - 设置自动检查的频率（每天 / 每周 / 每月）
- **手动检查** - 点击「检查更新」立即检查

当发现新版本时：

- 顶部工具栏设置按钮旁会显示**绿色版本号**（如 `v1.2.0`），点击可直接跳转到对应的 Release 页面下载
- 设置面板的更新区块会显示新版本信息和操作按钮

**跳过版本：** 如果不想升级到某个版本，可以点击「跳过此版本」，之后不会再提醒该版本。在设置面板中可以查看已跳过的版本，点击 ✖ 可取消跳过。

### 快捷键自定义

所有可自定义的快捷键都可在设置中修改。点击快捷键设置中的输入框，然后按新的键组合即可。

**注意：** 名称带下划线的快捷键表示已被自定义，不再是默认值。

不可编辑的快捷键（系统保留）：
- Esc - 关闭当前对话框/窗口
- F1 - 切换帮助
- 方向键 - 在列表中导航

### AI 配置

配置 AI 模型用于自然语言辅助：

- **启用 AI** - 开启/关闭 AI 功能
- **激活模型** - 选择要使用的 AI 模型
- **执行前确认** - 执行 AI 生成的命令前显示确认对话框
- **最大轮次** - 代理模式下的最大对话轮数
- **渲染 Markdown** - 使用 Markdown 格式显示 AI 回复

**添加模型步骤：**
1. 点击 "+ 添加模型"
2. 输入模型名称（用于显示）
3. 选择提供商（OpenAI、Azure 等）
4. 输入模型 ID（如 `gpt-4`、`gpt-3.5-turbo`）
5. 输入 API 地址（或使用默认）
6. 输入 API 密钥
7. 调整温度参数（0.0-2.0，越低越确定）
8. 点击 "测试连接" 验证
9. 点击 "保存"
